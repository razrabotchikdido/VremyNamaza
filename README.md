# Время Намаза (VremyNamaza) 🕌

Мобильное приложение для Android, помогающее точно соблюдать время намаза, определять направление Киблы и слушать Азан.

## ✨ Основные функции:
*   **Точное время намаза:** Расчет по GPS с учетом выбранного метода.
*   **Компас Киблы:** Плавный и точный датчик направления на Каабу.
*   **Уведомления:** Оповещения о начале намаза и прослушивание Азана.
*   **Кастомизация:** 5+ тем оформления (Темная, Светлая, Сепия, Уголь, Изумруд, Полночь).
*   **Локализация:** Поддержка русского, английского и арабского языков.
*   **Виджеты:** Удобные виджеты для рабочего стола и шторки уведомлений.
*   **Новый дизайн списка намазов** со стильными векторными иконками.
*   **Список из 5 обязательных намазов** (без Восхода).
*   **Обновленное окно «О программе»** с пульсирующей кнопкой Telegram.
*   **Улучшения** стабильности и быстродействия.

## 🛠 Технологии:
*   Kotlin
*   Jetpack Compose
*   Material 3

# Prayer Times (VremyNamaza) 🕌

An Android mobile application designed to help users accurately track prayer times, find the Qibla direction, and listen to the Adhan.

## ✨ Key Features:
*   **Accurate Prayer Times:** GPS-based calculation using selected methods.
*   **Qibla Compass:** Smooth and precise sensor for the Kaaba direction.
*   **Notifications:** Alerts for prayer times and Adhan playback.
*   **Customization:** 5+ app themes (Dark, Light, Sepia, Charcoal, Emerald, Midnight).
*   **Localization:** Support for Russian, English, and Arabic languages.
*   **Widgets:** Convenient widgets for the home screen and notification shade.
*   **New Prayer List Design** with stylish vector icons.
*   **5 Obligatory Prayers List** (Sunrise excluded).
*   **Updated "About" Screen** with a pulsing Telegram button.
*   **Performance and stability improvements.**

## 🛠 Tech Stack:
*   Kotlin
*   Jetpack Compose
*   Material 3
